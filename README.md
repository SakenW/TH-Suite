# TransHub Suite

Multi-product translation suite for games and applications.

## Directory Structure

- `packages/` - Projects and Products
    - `minecraft/`
        - `products/game-desktop` - Minecraft Modpack Translator
- `shared/` - Shared libraries (core, ui, fs, crypto)
- `tools/` - Build tools and templates

## Commands

- `pnpm install`
- `pnpm build`
- `pnpm dev`
