### 次要问题：初始化器过度重建

**原问题**：`db_initializer.py:99` 在视图缺失时重建整个数据库
**修复方案**：新增 `_recreate_views_only()` 方法，仅重新创建视图和索引

```python
# 修复前：清除所有数据
return self._create_database()  

# 修复后：保留数据，仅重建视图
return self._recreate_views_only()
```
