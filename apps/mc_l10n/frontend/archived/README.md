# 归档文件说明

此目录包含TH-Suite MC L10n前端项目的归档文件，按类型组织：

## 目录结构

### `legacy-components/`
存放已废弃的旧版组件文件：
- 旧版Material-UI组件
- 废弃的Minecraft主题组件  
- 不再使用的UI组件

### `legacy-pages/`
存放已废弃的旧版页面文件：
- 旧版页面组件
- 废弃的路由页面
- 不再使用的页面布局

### `test-files/`
存放测试和调试文件：
- 测试页面
- 调试组件
- 临时测试文件

### `backup-files/`
存放备份文件：
- .backup 扩展名文件
- .old 扩展名文件
- 其他备份文件
